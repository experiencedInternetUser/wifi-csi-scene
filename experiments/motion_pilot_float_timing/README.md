# Пробные запуски до исправления обработки времени

Папка сохраняет девять завершённых обучений CNN-GRU с `logamp`, их веса, валидационные предсказания, кривые обучения и исходный план. Запуски использовали прежние 3045 окон. После независимой проверки времени основное исследование перенесено в [motion_results](../motion_results): разрывы теперь сравниваются с 50 000 в целых микросекундах, а набор содержит 3052 окна.

Эти девять запусков не входят в выбор итоговой модели, сводные метрики и графики нового исследования. Файлы `train_snapshot.py` и `pipeline_snapshot.py` фиксируют код пробного запуска; это архивные копии, а не отдельные команды воспроизведения. В контрольных суммах `plan.json` сохранена связь с этой версией кода. Начатое обучение TCN было прервано; его завершённого файла весов здесь нет.

`benchmark.csv` относится к предварительным измерениям. Для итогового выбора используются измерения из [основного эксперимента](../motion_results/benchmark.csv).
