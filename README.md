# Обнаружение движения по Wi-Fi CSI

В проекте обучен бинарный детектор по четырём секундам CSI. Проверенная задача — ходьба или ходьба с махами руками против пустой сцены. Неподвижный присутствующий человек в отрицательном классе не представлен, поэтому качество полного различения «любое движение / нет движения» пока не установлено.

## Итоговая модель

По результатам 126 валидационных обучений выбрана **Causal TCN с подавлением выбросов, ФНЧ 20 Гц и центрированием** (`hampel_lp20`), 46 081 параметр. Средняя balanced accuracy по трём исключаемым доменам и трём seed — 0,9219. При отставании не более 0,005 от лучшей оценки критерием служило измеренное время обработки на CPU.

После выбора выполнены десять контрольных обучений с пятью seed. Для заранее назначенного seed 42:

| Обучение | Контроль | Окон | Balanced accuracy | F1 | FP | FN |
|---|---|---:|---:|---:|---:|---:|
| 33 записи Wallhack без NLOS/PIFA | NLOS/PIFA | 352 | 0,9506 | 0,9723 | 11 | 2 |
| Все 44 записи Wallhack; итоговые веса | 3DO, три дня | 1589 | 0,9991 | 0,9991 | 0 | 1 |

Контрольные домены использовались в прежней исследовательской сетке, поэтому это ретроспективная проверка. Результаты относятся к доступным записям и не заменяют тест в новом помещении.

- [Описание детектора](research/motion_model_report.md) — принцип работы, данные, предобработка, устройство модели, качество и использование. Формулы, параметры и полные таблицы собраны в справочной части.
- [Итоговые веса deployment.pt](experiments/motion_results/deployment.pt) — сеть, параметры нормализации, порог и метаданные обучения; seed 42, обучение на всех 44 записях Wallhack.
- [Код нового эксперимента](experiments/final_motion) — подготовка, обучение, загрузка модели, проверка и численный анализ.
- [Все новые результаты](experiments/motion_results) — 136 файлов весов, предсказания, кривые, таблицы и протокол.

Независимая проверка исходных CSV выявила ошибку сравнения времени ровно на границе 50 мс. В новом эксперименте интервалы и сетка ресемплирования рассчитываются в целых микросекундах. После исправления подготовлены 3052 окна из 67 записей. Веса, прогнозы и таблицы нового эксперимента доступны для добавления в Git; большой восстанавливаемый массив амплитуд остаётся локально. Скрипты построения новых графиков удалены, PNG и численные данные сохранены.

Пример загрузки итоговой модели на CPU:

```python
import torch
from experiments.final_motion.pipeline import MotionDetector

torch.set_num_threads(1)
detector = MotionDetector("experiments/motion_results/deployment.pt")
# amplitudes: неотрицательный массив [N,52,400], 100 Гц, до нормализации.
# Поднесущие L-LTF: [6:32] + [33:59].
probability = detector.predict(amplitudes)
movement = probability >= detector.threshold
```

Команды воспроизведения приведены в итоговом отчете. Архивы Wallhack и 3DO нужны для подготовки; готовый файл весов загружается без них.

## Исходная сетка из 256 обучений

Ниже сохранены результаты сетки на прежних 3045 окнах. Для обучения использованы записи Wallhack1.8k и 3DO. Данные разделены по полным записям и доменам: окна одной записи никогда не попадают одновременно в обучение и тест.

Выполнено 256 обучений: четыре архитектуры × четыре варианта предобработки × 16 схем разделения. Код, подготовленные данные, веса и предсказания собраны в одной папке [experiments](experiments). Исходные архивы датасетов загружаются отдельно.

### Полученные результаты

В таблице показана средняя balanced accuracy по 16 сценариям. Эта метрика усредняет полноту распознавания движения и фона, поэтому учитывает оба класса даже при разном числе окон.

| Предобработка | TinyCNN | Causal TCN | CNN-GRU | Tiny Transformer |
|---|---:|---:|---:|---:|
| `logamp` | 0.6281 | 0.6256 | 0.6088 | 0.6618 |
| `relative` | 0.8206 | 0.9132 | 0.9215 | 0.9119 |
| `relative_diff` | 0.7391 | 0.7396 | 0.7274 | 0.7985 |
| `lp20_centered` | 0.8543 | 0.9609 | 0.9594 | 0.9372 |

Лучшие средние оценки получены у Causal TCN и CNN-GRU после фильтрации и центрирования `lp20_centered`. Их средний F1 — 0.9734 и 0.9672 соответственно. При этом результат зависит от направления переноса. Например, для этой же предобработки:

| Обучение → тест | Causal TCN, balanced accuracy | CNN-GRU, balanced accuracy |
|---|---:|---:|
| Wallhack → 3DO | 0.9991 | 1.0000 |
| 3DO → Wallhack | 0.7964 | 0.9491 |

Обучения проведены с одним seed. В текущих данных отрицательный класс — пустая сцена, положительный — ходьба или ходьба с махами руками. Проверки неподвижного присутствующего человека пока нет. Для выбора итоговой модели нужны повторы с другими seed и новые записи.

При усреднении каждый сценарий имеет одинаковый вес. Если тест включает несколько доменов, сначала метрика считается по всем их предсказаниям (`ALL`). Подробности и все результаты:

- [Отчёт об экспериментах](research/experiment_results.md) — подготовка данных, разбиения и таблица всех 256 обучений.
- [Результаты по доменам](research/experiment_results_by_domain.md) — 656 строк метрик, число примеров и матрицы ошибок.
- [Протокол обучения](experiments/protocol.md) — параметры запуска и правила проверки.

### Какие модели обучались

Все модели получают амплитуду CSI формы `[52, 400]` и возвращают один логит. После sigmoid значение от 0.5 считается движением. Определения находятся в [experiments/models.py](experiments/models.py).

| Модель | Устройство | Параметров |
|---|---|---:|
| TinyCNN | Три двумерные свёртки с 16/32/64 каналами, GroupNorm и усреднением признаков | 26 849 |
| Causal TCN | Семь остаточных временных блоков с 32 каналами и дилатациями от 1 до 64; ответ по последнему состоянию | 46 081 |
| CNN-GRU | Две временные свёртки с уменьшением длины последовательности и GRU на 64 состояния | 43 681 |
| Tiny Transformer | Патчи по 8 отсчётов, размерность 64, два слоя энкодера и четыре головы внимания | 96 897 |

### Данные и предобработка

| Набор | Использованные записи | Домены | Окон по 4 с |
|---|---:|---|---:|
| [Wallhack1.8k](https://zenodo.org/records/15147388) | 44 | `LOS/BQ`, `LOS/PIFA`, `NLOS/BQ`, `NLOS/PIFA` | 1460 |
| [3DO](https://zenodo.org/records/10925351) | 23 | Дни `d1`, `d2`, `d3` | 1585 |
| Всего | 67 | | 3045 |

В 3DO используются только полные записи фона `b*` и ходьбы `w*`. Записи сидения и лежания исключены: они содержат движения, но не имеют подходящих интервальных меток. В Wallhack классы ходьбы и ходьбы с махами руками объединены.

UT-HAR, NTU-Fi HAR, NTU-Fi HumanID и подготовленный Widar были просмотрены, но не включены в бинарное обучение: в доступных архивах нет размеченного класса «нет движения». Для UT-HAR также отсутствуют исходные идентификаторы записей, необходимые для разделения по сессиям.

CSI читается из исходных CSV с восстановлением действительной и мнимой компонент. Выбираются 52 поднесущие L-LTF, вычисляется амплитуда, исправляются переполнения таймера. Пропуски более 50 мс разделяют запись. Внутри непрерывных частей сигнал интерполируется на 100 Гц и делится на неперекрывающиеся окна по 400 отсчётов.

| Вариант | Что делается с амплитудой `A` |
|---|---|
| `logamp` | Логарифм `log(1 + A)` |
| `relative` | Отклонение от среднего каждой поднесущей в текущем окне: `A / max(mean_time(A), 1) − 1` |
| `relative_diff` | Первая временная разность `relative`; первый отсчёт равен нулю |
| `lp20_centered` | Причинный фильтр Баттерворта 4-го порядка с частотой среза 20 Гц, затем вычитание среднего окна |

После преобразования среднее и стандартное отклонение каналов рассчитываются только по обучающей выборке и применяются к тестовой без пересчёта.

Проверены четыре направления разделения: один домен → остальные, несколько доменов → оставшийся, Wallhack → 3DO и 3DO → Wallhack. Для Wallhack доступны схемы 1→3 и 3→1; для трёх дней 3DO — 1→2 и 2→1. Вместе это 16 сценариев.

Файлы одной конфигурации имеют общее имя, например `wh_to_td__lp20_centered__tcn__s42`: перенос Wallhack → 3DO, указанная предобработка, TCN и seed 42.

В [research/analysis/README.md](research/analysis/README.md) описан каждый файл первичного анализа. Он охватывает 95 исходных записей, включая сидение и лежание. Его линейный классификатор и нейросетевая сетка на 67 записях используют разный состав классов, поэтому их оценки рассматриваются отдельно.

Ноутбук `csi_datasets_exploration.ipynb` сохраняет первый просмотр форматов. Он ожидает распакованные наборы в `datasets/unpacked/`; при необходимости пути меняются в ячейке `PATHS`. Для обучения используется `prepare.py`, который читает ZIP напрямую. Старые оценки ноутбука в результаты сетки не входят.

### Запуск

Проверенное окружение: Python 3.12.10, PyTorch 2.5.1 с CUDA 12.1; обучения выполнялись на NVIDIA GeForce RTX 3080 Ti Laptop GPU. Команды выполняются из корня проекта.

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

Для просмотра таблиц и обновления отчётов исходные архивы не нужны:

```powershell
python experiments/report.py
```

Для полной проверки нужны сохранённые массивы, веса, предсказания и CUDA GPU:

```powershell
python experiments/resume.py --check
python experiments/validate.py
```

Проверка пересчитывает все 656 строк метрик, проверяет 256 файлов весов, 64 набора параметров стандартизации и повторяет предсказания четырёх архитектур. Записи и домены обучения и теста не пересекаются. Последняя полная проверка пройдена; вероятности после загрузки весов совпали с сохранёнными.

Чтобы заново подготовить данные, положите `3DO.zip` и `wallhack1.8k.zip` в `datasets/`, затем выполните:

```powershell
python experiments/prepare.py
python experiments/resume.py
```

`resume.py` пропускает уже завершённые запуски. В сохранённой сетке готовы все 256 обучений. Параметры этой сетки менять нельзя: для нового эксперимента нужна отдельная копия результатов и новый план. Все модели обучались 20 эпох с seed 42, размером батча 64 и порогом 0.5; подробные настройки — в [протоколе](experiments/protocol.md).
