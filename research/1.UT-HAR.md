# SenseFi: A library and benchmark on deep-learning-empowered WiFi human sensing

Смысл работы: создать библиотеку для сравнения методов глубокого обучения на данных Wi-Fi CSI. Авторы реализовали несколько архитектур нейросетей и проверили их на разных датасетах для распознавания действий человека.

| Характеристика                      | UT-HAR                   | NTU-Fi HAR               |
| ----------------------------------- | ------------------------ | ------------------------ |
| Задача                              | Распознавание активности | Распознавание активности |
| Число классов                       | 7                        | 6                        |
| Обучающая выборка в бенчмарке       | 3977                     | 936                      |
| Тестовая выборка в бенчмарке        | 996                      | 264                      |
| Оборудование сбора                  | Intel 5300 NIC           | Atheros CSI Tool         |
| Формат обработанных данных в репозитории исследования | `1 × 250 × 90`           | `3 × 114 × 500`          |
| Классы | lie down, fall, walk, pick up, run, sit down, stand up | box, circle, clean, fall, run, walk

Cовпадают только три класса: падение, бег и ходьба.

Данные, собранные с помошью Nexmon CSI Tool, довольно зашумлены (поэтому авторы используют другое оборудование).

## Данные от CSI

Данные CSI представляют собой вектор комплексных чисел, включающий амплитуду и фазу.

В качестве входных данных обычно используются только данные об амплитуде
